# キャラクターイラストの元データ

`character/<key>/*.webp` を作る元になったPNG。

**このPNGはリポジトリに入っていない。** 27枚で11MBあり、クローンが重くなる
ため `.gitignore` の `*.png` で除外している（`character/` と `icons/` だけ
例外にしてある）。手元で素材を整備するときに置く場所、という位置づけ。

```
# WebPへの変換（この環境では ImageMagick を使った）
convert Task/art-source/neko/normal.png -quality 85 \
  -define webp:alpha-quality=100 character/neko/normal.webp
```

`scripts/check-mascot-art.mjs` はこちらのPNGを見て、
**本体から切り離された塊**（背景を抜いたときの消し残し）を検出する。
WebPは自前でデコードできないので、検査は変換前のPNGに対して行う。
上記のとおりPNGはリポジトリに無いので、**この検査はCIでは動かない**。
飛ばしたときは検査が「消し残し検査は未実施」と出すので、
素材を差し替えるときは手元で一度通すこと。

## 手を入れた記録

### neko（2026-11-08 受領ぶん）

納品された9枚のうち4枚に、本体から切り離されたかけらが浮いていた。
いずれも体の反対側に完全なしっぽ・耳が別途あり、明らかな消し残し。
目視で確認したうえで、`scripts/strip-stray-blobs.mjs` で該当する
連結成分だけを透明化した（矩形で塗ると本体を削るため）。

| ファイル | 消した塊 | 正体 |
|---|---|---|
| sparkle  | 576px  (x425-434, y406-485) | しっぽ |
| thinking | 1394px (x417-434, y393-500) | しっぽ |
| troubled | 2500px (x407-434, y383-506) | しっぽ |
| sleepy   | 4333px (x394-434, y377-516) | しっぽ |
| sleepy   | 783px  (x423-434, y141-229) | 耳の先 |

頭の上の塊（happy の `!!`、sparkle の `✨`、thinking の `?`、
sleepy の `zZ`、wave の `!!`）は意図した効果線なので残してある。
位置だけで機械的に切ると効果線まで消えるので、検査も
「下半分にある離れた塊」だけをエラーにしている。

**次に素材を依頼するときは、背景の抜き残しが無いことを条件に加えること。**

### 3キャラ（2026-11-21 受領ぶん・v3）

neko / akita / kuma の27枚を受け取り、neko も新しいものに差し替えた。

ここに至るまでに2回やり直してもらっている。何が起きたかを残しておく。

**1回目**: 各コマの左端に隣のコマを縦に切った切れ端（耳・バンダナ・前足）が
写り込んでいた。18枚中16枚。1枚のシートに並べてから切り分けたため。
さらに `wave` だけキャラの位置と大きさが違い、効果マークが隣のコマに
入っていた（`thinking` に ✨、`troubled` に ?）。

**2回目**: 写り込みと位置ズレは直ったが、9枚すべてが「`normal` の絵に
部品を貼っただけ」になっていた。`normal` との差分を取ると、変化が
貼られた部品だけで、しかも**3体とも同じ座標**に貼られていた。
閉じた目の線が本物の目とズレた位置に乗って灰色のにじみが出ており、
`thinking` は顔がまったく変わらず「?」だけ、`wave` は棒の先に丸が
付いた物体が胸に貼られていた。

**3回目（採用）**: 9枚それぞれが別の絵として描かれた。本体の画素数が
コマごとに違うことで確認できる。足元は27枚すべて y=544〜545（1px差）、
離れた塊は効果マーク（? 💧 ✨ zZ !!）だけで全部上半分。

#### 受領後にこちらでやったこと

1. `scripts/crop-art-canvas.mjs` で、9枚の不透明領域の和集合を取って
   同じ矩形で切った（1枚ずつ切ると表情を変えるたびにキャラが動く）
2. **3キャラの「体の高さ / 画布の高さ」を揃えた。** 切り詰めただけだと
   効果マークの広がりがキャラごとに違うぶん画布の比率がズレ、
   犬と熊が猫より1割ほど大きく見えた。足元を動かさないよう
   **上にだけ透明を足して**、いちばん背の高い画布（563px）に合わせている。
   `object-fit: contain` + `object-position: center bottom` で描くので、
   上に足せば見かけの大きさだけが揃う
3. WebPに変換（27枚で776KB。元PNGは11MB）

**次に素材を依頼するときの条件**（3回ぶんの学び）:

- 9つの表情を1枚ずつ別ファイルで書き出す（シートから切り分けない）
- 部品を貼るのではなく、9枚それぞれを1枚の絵として描く
- 9枚すべてで体の位置と大きさを同じに、足元の高さを揃える
- 効果マークはキャラごとに位置を合わせる
- 背景の抜き残しが無いこと
